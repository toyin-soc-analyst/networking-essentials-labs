Welcome to my networking study repository. This project documents my progress through technical labs and fundamental networking concepts, focusing on protocols, packet analysis, and network architecture.Table of ContentsDHCP: The DORA ProcessARP: Layer 3 to Layer 2 AddressingICMP: Ping Echo ReplyNAT: Network Address TranslationDHCP: The DORA ProcessThe Dynamic Host Configuration Protocol (DHCP) automates network configuration, providing devices with necessary details like IP addresses, subnet masks, default gateways, and DNS servers. The DORA process follows four steps:Discover: The client broadcasts a DHCPDISCOVER message seeking a local DHCP server.Offer: The server responds with a DHCPOFFER message with an available IP address.Request: The client responds with a DHCPREQUEST message to accept the offered IP.Acknowledge: The server responds with a DHCPACK message to confirm the IP assignment.ARP: Layer 3 to Layer 2 AddressingARP bridges the gap between IP (Layer 3) and data link (Layer 2) addresses. When communicating over Ethernet or WiFi, devices must resolve physical MAC addresses to construct data link headers, even when the target IP address is known. The Ethernet frame header includes:Destination MAC address: The receiving device's physical address.Source MAC address: The sending device's physical address.Type: Specifies the encapsulated protocol, such as IPv4 (0x0800).ICMP: Ping Echo ReplyThis capture displays an ICMP "Echo (ping) reply" message (Type 0) received in response to an initial request.Protocol Details: The packet identifies the ICMP Type as 0.Response Timing: The capture includes a response time of 23.903 ms.Data Payload: The payload consists of 40 bytes of data.NAT: Network Address TranslationNAT is used to map multiple private IP addresses to a single public IP address, solving IPv4 address depletion. NAT-supporting routers maintain a translation table to map internal IP/port combinations to external ones.Capacity Limitation:The router's capacity is limited by available TCP ports ($2^{16} = 65,536$), resulting in approximately 65 thousand simultaneous connections per public IP address.Documented by Oluwatoyin Oyedijo as part of professional development in Cybersecurity and Networking.
